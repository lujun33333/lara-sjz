# 三角洲当前 IPA 自瞄控制链（静态证据）

样本：`三角洲行动-cn..ipa`，版本 `1.201.37117 (68)`。附加模块 `iTopDns_dylib` 的 UUID 为 `3c4bb519-bd5d-3ce2-a44f-7febe809a8ab`，SHA-256 为 `436fac659baefb574512bbda279d7ec3bce383cb58703ab18789ed3a00dc25d4`。下表是该模块未滑移 VA；`__common` 变量为零填充内存，没有 IPA 文件偏移。

| 变量 VA | 模块原生含义 | 静态生产与消费 |
| --- | --- | --- |
| `0xd01b78` | `Predict Perfect Aimbot` 开关，配置键 `aim` | 菜单 `0x1f6b94–0x1f6ba4` 传入布尔指针；配置读回 `0x1ecbb8` 写入；`0x20b2b4`、`0x20b9a8` 读取并进入目标选择和角度计算链。 |
| `0xc38390` | `Aim When`：0 Always、1 Scope、2 Weapon | 菜单 `0x1f6c30–0x1f6c7c` 传入选择索引；执行路径读取。 |
| `0xc38394` | `Speed AIM` | 菜单 `0x1f6bc8–0x1f6be4` 传入 0–1 浮点滑条；执行路径读取。 |

| `0xd01b7c` | `Target`：0 Head、1 Chest、2 Legs | 菜单 `0x1f6d30–0x1f6d8c` 分别传入索引 0、1、2；独立 UI 的 0 胸、1 头需要映射。 |

`Silent Track` 使用另一个开关 `0xd01b56`，配置键 `silenttrack`。它控制武器虚表 hook，与上述 `Predict Perfect Aimbot` 分开；外部适配器不自动启用它。模块从本地角色的 `pawn+0x1788` 取得当前武器，再由 `weapon+0x4b0` 取得对象，替换其虚表 `+0x40` 槽为 `0x2113b8`。Hook 调用原虚函数后，可向第三参数 `x2` 写 12 字节角度候选。模块计算结果缓冲 `0xd01b58` 会在计算路径重写，不适合作为外部程序的稳定写入点。

外部 App 的原生模块路线只对这一已带 `iTopDns_dylib` 的 IPA 适用。源码对主程序和模块版本进行校验，向模块自身的开关及参数写入并读回；停止时尝试恢复本次修改前的值。它不使用旧样本的 `controller+0x3d8`。静态读取消费链与写后读回只证明配置到达模块，**还不能证明三角洲真机镜头移动或命中效果**。独立虚拟触摸实验是另一条路线，也需设备上确认 HID 事件到达游戏和相机反馈。
