# 2026-10-01 真机反馈修复

基于 aff2b7e 的测试日志，采集链单帧 2.17–17.73 秒，5 次成功呈现随后约 470 ms 清屏。自瞄没有到达输出阶段；3 个正常采集帧参数为零，另 2 帧没有合格候选。

本次修正：

- 根页刷新留下的空槽优先复用，不再无故驱逐热页；容量耗尽时仍使用 FIFO。
- 血量 8 字段与固定 18 点骨骼批读，保留有限值、指针稳定、完整骨点检查；不可整段读取时回退逐字段读取。
- actor 头批读复用、成功 FName 解码缓存；完整分类且明确无关的实体每帧轮转复核 32 个，正实体与读取失败始终重新读取。根、会话、数组地址和相关开关变化失效。
- 零速度/范围在清缓存前退出；保留 cn 默认零值。日志记录实际参数、可写能力、自瞄目标、骨骼/投影/半径拒绝数及三个阶段耗时。
- HUD 的 450 ms 时效从采集起始计算，过期来源不会在接收时重新续命。未放宽根、实体身份或列表变化检查。

实际验证：18 组回归通过，主要 C++ 链使用 ASan/UBSan；源码一致性通过；iPhoneOS16.5 SDK arm64 HUD/采集/传输语法检查通过；相关 C++ 的 GCC fanalyzer 与人工差分审查通过。128 actor 模拟场景预热后每帧 69 次读取、0 次 FName 远程读取；连续 1000 次根页刷新保持其他热页。

这些结果不证明手机帧率或游戏视角响应。macOS 完整构建结果见对应提交的 Actions；真机需要本次新 IPA 日志验证。原 aff2b7e 的验证记录只对应旧提交，不能替代本次检查。
